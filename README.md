# Credit Card Debugging Lab

A compact Java 17 + JUnit 5 project for a one-hour graduate debugging workshop.

The scenario is inspired by LinkedIn Learning's *Java's Toughest Bugs* payment-method example.

## Student starting point

Run `PaymentDebuggingTest`. Several tests fail. Treat each failing test as a bug report and use the debugger rather than
reading every class first.

Requires Java 17+ and Maven 3.9+.
